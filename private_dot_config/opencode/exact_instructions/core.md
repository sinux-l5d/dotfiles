# Core

- Use Bash for running terminal commands.
- Use Nushell only for scripts or when explicitly asked.
- Do not install anything manually. For version-sensitive CLI tools (for example, `kubectl`, `helm`, Go, or Rust), check Mise first. If Mise does not provide it, or it is an app where the version does not matter, check Homebrew. Stop and ask the user for permission before installing anything.
